# Changelog

## 1.0.0 — 2026-11-22

- First Traffic Monitor release, derived from luci-app-nlbw-history 1.1.0.
- Preserve the existing customized Live, History and Settings interface.
- Use a dedicated package, service, configuration, RPC and data namespace.
- Consolidate version-suffixed development assets into stable module names.
- Add migration with backups, history verification and counter-baseline transfer.
- Preserve legacy local-custom URL and browser-preference compatibility.
- Keep nlbwmon for historical accounting and conntrack for live rates.
